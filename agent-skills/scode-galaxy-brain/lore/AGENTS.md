# Lore directory

NOTE: This directory is a historical archive, not living documentation. Do not read these files during normal work on
the skill; use them only when digging into why a past decision was made.

Files are named `YYYY-MM-DD-<topic>.md`, dated by when the decision or event they record happened. Each file is a
point-in-time record: it describes what was known and decided then, and it is expected to drift out of sync with the
skill as the skill evolves. That drift is not a defect. Do not "maintain" these files, update them to match current
code, or fix claims that have since become stale. They are immutable once created — edit or delete one only when the
user explicitly asks for that specific change.
