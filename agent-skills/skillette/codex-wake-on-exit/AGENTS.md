# Changing Codex wake-on-exit

Read [EVALS.md](EVALS.md) before changing this skillette. Keep its discovery and receipt scenarios current, and add a
regression case when fixing a failure an agent could repeat. Keep the parent [specification](../SPEC.md) consistent.

Evals are opt-in. Run them when requested, using the user's model and effort when specified. Record actual runtime and
model details in the results; do not hardcode a model in the maintenance procedure.

`CLAUDE.md` is a relative symlink to this file. These maintenance instructions and `EVALS.md` are outside the ordinary
use loading path.
