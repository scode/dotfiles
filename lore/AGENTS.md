# Lore directory

Lore notes in this directory are historical artifacts. They capture design notes, experiments, and context that was
useful when written, but they are not living project documentation.

Do not maintain lore notes during ordinary refactors, renames, behavior changes, or documentation cleanup. If a lore
file is stale, leave it stale unless the task is specifically to add or amend historical context.

When adding a new lore file, prefer a dated filename and make the scope clear near the top.
